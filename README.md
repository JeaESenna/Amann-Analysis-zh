## 三卷的翻译与审校情况（重要：三卷质量不同）

三卷不是在同一个时期、用同一套流程完成的，**审校强度与可靠性差异明显**，请按卷区别对待：

| 卷 | 采用的流程 | 审校强度 | 主要已知问题 |
|---|---|---|---|
| 《分析学 I》 | 最早期完成：以 **OCR（PaddleOCR）识别出的英文文本** 为底本，AI 翻译后人工按页抽看 | **没有走三线审校**（全书只有 1 个单元做过 pilot 审校）；只有数学逐页核验 + 程序化校验 + 一次性修补 | OCR 错误较多：数学核验已按原书修正 36 处，但仍有整类缺失（如显示公式编号 `\tag` 系统性丢失、第 II/III/V 章部分脚注正文在 OCR 源中缺失）；TeX 由早期转换管线生成，排版代码较粗糙；交付后才发现缺 14 条脚注（2026-10-26 修订版才补齐） |
| 《分析学 II》 | 成熟流程：页图视觉转录 → 翻译 → 构建 → **三线审校** → 修复 → 双闸门 | 第 VI–VIII 章与前置页全部经过 **math / translation / layout 三线审校**，审校闸门与质量闸门（review / quality 双闸门）全部 PASS | 少量已登记、未在交付版修正的问题：9 处行内公式空格（书写规范检查待办）、1 处术语需改译文、约 40 条术语待人工裁决；原书自身的排印缺陷按原则原样保留并登记 |
| 《分析学 III》 | 第 IX 章为完整三线轮；第 X–XII 章因**成本**限制改用「省钱版」流程（合并视觉转录 + 翻译、降低推理档位） | 第 IX 章三线全量（42 份报告）；第 X–XII 章 **math + translation 双线全量**（不抽样），但 **layout（排版）审校按预算暂缓，审校闸门记为 SKIPPED（不是 PASS）** | 第 X–XII 章**没有排版审校线**；md ↔ 页图机械核对改用卷内替代脚本；原书索引不收入、参考文献英文原样 |

**结论（请据此调整使用方式）**：

- **第二卷**流程最完整、审校最充分，可靠性相对最高；
- **第三卷**第 IX 章与第二卷同档；第 X–XII 章只有双线审校，**版面与公式落位相关问题的风险更高**；
- **第一卷最粗糙**：OCR 遗留错误与排版问题相对最多，且没有三线审校，建议只作阅读参考，数学细节务必对照原著。

三卷都由 AI 辅助完成，均**不是**出版社级编校。引用、教学与考试请以 Amann–Escher 原著（英译本或德文原版）为准。

## 仓库结构

每个 `analysis-N/` 目录都是自包含的，可以整体上传，也可以按卷拆成三个独立仓库。

```text
analysis-N/
├─ README.md                 本卷说明
├─ *.pdf                     成品 PDF（本卷）
├─ translations/zh-CN/       译文源（Markdown，唯一真源）
│  ├─ chapter-00/           出版信息 + 前言
│  ├─ chapter-01/ …         正文各章，一节（或一个习题单元）一个 .md
│  └─ …
├─ tex/                      XeLaTeX 排版源
│  ├─ main*.tex             装订文件（导言区 + 逐章 \input）
│  ├─ qyxf-book.cls         文类（定理环境、版式）
│  ├─ preamble/             书籍信息与宏、Unicode 字符映射
│  ├─ qyxf/                 各章排版源（前置页 + 各章）
│  └─ figures/              插图（md 与 tex 共用同一批图片）
└─ glossary/                术语表、符号表
```

## 关于译文源（Markdown）

- `translations/zh-CN/` 按章、按节组织；**一节一个文件**，文件名形如 `ch1-02_sets.md`。
- 数学公式用 LaTeX 语法：行内 `$...$`，行间 `\[ ... \]`；定理、证明、列表等按章节语义书写。
- 图片引用统一指向 `tex/figures/` 下的文件，例如 `../../../tex/figures/<hash>.jpg`。
- 译文源是生成排版稿的输入，与 `tex/` 中的排版结果逐节对应；构建管线标记已在本仓库中剔除。
- 书前「译者的话」由排版流程写入前置页，**只存在于 tex 前置页**
  （`tex/qyxf/00-front-matter.tex`），不在 Markdown 中。

## 关于排版源（TeX）

- 引擎：**XeLaTeX**（TeX Live 2025 实测通过），文类为 `qyxf-book.cls`
  （基于「钱院学辅」书籍模板修改）。
- 编译命令（在每卷的 `tex/` 目录下执行）：

  ```powershell
  $env:TEXINPUTS = (Get-Location).Path + ';'
  xelatex -interaction=nonstopmode main.tex
  xelatex -interaction=nonstopmode main.tex
  ```

  第一卷主文件为 `main-qyxf.tex`。需要跑两遍，目录与交叉引用才正确。
- 字体：Windows 自带宋体 / 黑体 / 楷体，数学字体使用 TeX Live 的 XITS；其它系统可能需要调整字体配置。
- 三卷页数分别为 **330 / 329 / 387** 页。
