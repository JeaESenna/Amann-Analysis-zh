# 符号表

> 本表说明符号的处理方式。**总原则：符号一律原样保留，不翻译、不改写、不重排。**
> 本表只说明含义与处理方式，供译者统一判断；不进入译文正文，不作为章节内容来源。

## 0. 处理总则

| 类别 | 处理 |
|---|---|
| 变量名、函数名、集合名 | 保留（$x$、$f$、$A$、$E$） |
| 数学常量与数集 | 保留（$\pi$、$e$、$\mathbb{N}$、$\mathbb{R}$） |
| 运算符与关系符 | 保留（$+$、$\cdot$、$\leq$、$\subseteq$、$\in$、$\to$、$\mapsto$） |
| 逻辑符号与量词 | 保留（$\land$、$\lor$、$\lnot$、$\Rightarrow$、$\Leftrightarrow$、$\forall$、$\exists$） |
| 上下标与指标 | 保留（$x_n$、$a_{ij}$、$\mathbb{K}^m$、$f^{-1}$） |
| LaTeX 命令、环境名、标签、引用键 | 保留（`\mathbb`、`\label`、`\ref`、`\begin{...}`） |
| 定界符 | 保留（$(\;)$、$[\;]$、$\{\;\}$、$\langle\;\rangle$、$|\;|$、$\|\;\|$） |
| 公式内标点 | 保留 |
| 公式与中文衔接处的标点 | 按中文习惯处理 |

## 1. 数集与常用集合

| 符号 | 含义 | 处理 |
|---|---|---|
| $\mathbb{N}$ | 自然数集 | 保留 |
| $\mathbb{N}^\times$ | 非零自然数集（即 $\mathbb{N}\setminus\{0\}$） | 保留 |
| $\mathbb{Z}$ | 整数集 | 保留 |
| $\mathbb{Q}$ | 有理数集 | 保留 |
| $\mathbb{R}$ | 实数集 | 保留 |
| $\mathbb{C}$ | 复数集 | 保留 |
| $\mathbb{K}$ | $\mathbb{R}$ 或 $\mathbb{C}$ | 保留 |
| $\mathbb{P}$ | 素数集 | 保留 |
| $\mathbb{R}^n$、$\mathbb{C}^n$、$\mathbb{K}^n$ | $n$ 维坐标空间 | 保留 |
| $\mathbb{R}^X$、$\mathbb{K}^X$ | 从 $X$ 到 $\mathbb{R}$／$\mathbb{K}$ 的映射全体 | 保留 |
| $\mathcal{R}$ | 原文中实数构造所用的环（Chapter II, §6） | 保留 |
| $\mathcal{T}(f,a)$ | 泰勒多项式相关记号 | 保留 |
| $\mathcal{R}_n(f,a)$ | 余项相关记号 | 保留 |
| $\overline{A}$ | 集合 $A$ 的闭包（Chapter III 起） | 保留 |
| $\mathring{A}$、$\operatorname{int}(A)$ | 集合 $A$ 的内部 | 保留 |
| $\partial A$ | 集合 $A$ 的边界 | 保留 |
| $\varnothing$、$\emptyset$ | 空集 | 保留 |
| $\{x \mid P(x)\}$、$\{x : P(x)\}$ | 描述法表示的集合 | 保留（分隔符按原文） |

## 2. 集合运算

| 符号 | 含义 | 处理 |
|---|---|---|
| $\in$、$\notin$ | 属于、不属于 | 保留 |
| $\subseteq$、$\subset$ | 包含于（子集） | 保留 |
| $\subsetneq$ | 真包含于 | 保留 |
| $\supseteq$、$\supset$ | 包含 | 保留 |
| $\cup$、$\bigcup$ | 并、任意并 | 保留 |
| $\cap$、$\bigcap$ | 交、任意交 | 保留 |
| $\setminus$ | 差集 | 保留 |
| $\triangle$、$\ominus$ | 对称差（原文所用记号） | 保留 |
| $\times$、$\prod$ | 笛卡儿积 | 保留 |
| $\mathcal{P}(X)$、$2^X$ | 幂集 | 保留 |
| $\operatorname{card}$、$\#$ | 基数 | 保留 |
| $\dot\cup$、$\biguplus$ | 不交并（原文所用记号） | 保留 |

## 3. 逻辑符号

| 符号 | 含义 | 处理 |
|---|---|---|
| $\land$、$\lor$ | 合取、析取 | 保留 |
| $\lnot$、$\neg$ | 否定 | 保留 |
| $\Rightarrow$、$\implies$ | 蕴含 | 保留 |
| $\Leftrightarrow$、$\iff$ | 等价 | 保留 |
| $\forall$、$\exists$、$\exists!$ | 全称量词、存在量词、唯一存在 | 保留 |
| $\therefore$、$\because$ | 所以、因为 | 保留 |
| $\square$、$\blacksquare$ | 证明结束符 | 保留 |
| $\def$、$:=$ | 定义符 | 保留 |
| $\models$ | 满足（逻辑） | 保留 |

## 4. 数系与序

| 符号 | 含义 | 处理 |
|---|---|---|
| $+$、$-$、$\cdot$、$/$、$\div$ | 四则运算 | 保留 |
| $\leq$、$<$、$\geq$、$>$ | 序关系 | 保留 |
| $\pm$、$\mp$ | 正负号 | 保留 |
| $|x|$ | 绝对值／模 | 保留 |
| $\operatorname{Re} z$、$\operatorname{Im} z$ | 实部、虚部 | 保留 |
| $\overline{z}$ | 复共轭 | 保留 |
| $\arg z$ | 辐角 | 保留 |
| $i$ | 虚数单位（原文记为 $i$，满足 $i^2=-1$） | 保留 |
| $n!$、$\binom{n}{m}$、$\binom{k}{\alpha}$ | 阶乘、二项式系数 | 保留 |
| $\operatorname{sgn}$ | 符号函数 | 保留 |
| $\sup$、$\inf$、$\max$、$\min$ | 上确界、下确界、最大、最小 | 保留 |
| $\infty$、$+\infty$、$-\infty$ | 无穷 | 保留 |
| $\sum$、$\prod$、$\sum_{k=0}^{n}$ | 求和、求积 | 保留 |
| $\gcd$、$\operatorname{lcm}$ | 最大公因子、最小公倍数 | 保留 |

## 5. 映射与函数

| 符号 | 含义 | 处理 |
|---|---|---|
| $f: X \to Y$ | 映射 | 保留 |
| $x \mapsto f(x)$ | 元素对应 | 保留 |
| $f \circ g$ | 复合 | 保留 |
| $f^{-1}$ | 逆映射／逆函数 | 保留 |
| $f \restriction A$、$f|_A$ | 限制 | 保留（按原文形式） |
| $\operatorname{id}_X$ | 恒等映射 | 保留 |
| $f(A)$、$f^{-1}(B)$ | 像、原像 | 保留 |
| $\operatorname{im} f$、$\ker f$ | 像、核 | 保留 |
| $Y^X$ | 从 $X$ 到 $Y$ 的映射全体 | 保留 |

## 6. 代数结构

| 符号 | 含义 | 处理 |
|---|---|---|
| $(G, \cdot)$、$(R, +, \cdot)$、$(K, +, \cdot)$ | 群、环、域 | 保留 |
| $e$、$1$、$0$ | 单位元、零元 | 保留 |
| $a^{-1}$、$-a$ | 逆元、负元 | 保留 |
| $G/H$、$R/I$ | 商群、商环 | 保留 |
| $\cong$ | 同构 | 保留 |
| $\operatorname{Hom}(G, H)$ | 同态集 | 保留 |
| $K[X]$、$K[X_1,\dots,X_n]$ | 多项式环 | 保留 |
| $K[\![X]\!]$ | 形式幂级数环（按原文记号） | 保留 |
| $\deg p$ | 多项式的次数 | 保留 |
| $\operatorname{char} K$ | 特征 | 保留 |
| $\dim V$ | 维数 | 保留 |
| $\operatorname{span}$、$\operatorname{lin}$ | 张成 | 保留 |
| $V \oplus W$ | 直和 | 保留 |
| $\mathcal{L}(V, W)$、$\operatorname{Hom}_K(V,W)$ | 线性映射空间（按原文记号） | 保留 |
| $\triangle_h$ | 差分算子 | 保留 |
| $p_m[f; x_0, \dots, x_m]$ | 牛顿插值多项式记号 | 保留 |
| $N[f; x_0; h]$ | 差商记号 | 保留 |
| $f[x_0, \dots, x_n]$ | 差商记号 | 保留 |
| $a^{\alpha}$、$\alpha!$、$|\alpha|$ | 多重指标记号 | 保留 |

## 7. 分析与拓扑（后续章节用，先登记）

| 符号 | 含义 | 处理 |
|---|---|---|
| $\varepsilon$、$\delta$、$N$ | 极限与连续性中常用字母 | 保留 |
| $\to$、$\lim$、$\limsup$、$\liminf$ | 收敛、极限、上极限、下极限 | 保留 |
| $\overline{\lim}$、$\underline{\lim}$ | 上极限、下极限（原文所用记号） | 保留 |
| $B(x, r)$、$\overline{B}(x, r)$ | 开球、闭球 | 保留 |
| $B(X, E)$、$C(X, E)$、$C^k$、$C^\omega$ | 函数空间 | 保留 |
| $\|x\|$、$\langle x, y \rangle$ | 范数、内积 | 保留 |
| $d(x, y)$ | 度量 | 保留 |
| $\partial_+ f$、$\partial_- f$ | 右导数、左导数 | 保留 |
| $f'$、$df/dx$、$Df$、$\dot{f}$ | 导数记号（原文并用多种记号） | 保留 |
| $N[f; x_0; h]$ | 牛顿插值余项 | 保留 |

## 8. 其他

| 符号 | 含义 | 处理 |
|---|---|---|
| $[1]$、$[Art91]$ | 参考文献引用 | 保留 |
| `Page 313`、独立数字（如 `2.3`） | 页码与编号 | 保留，不翻译 |
| `---`、`.....` | 目录中的引导点与破折号 | 保留 |
| `$ T_{EX}^{1} $` | OCR 对 TeX 的误识别（原文如此） | 原样保留 |
