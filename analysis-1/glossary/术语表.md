# 全局术语表

> 本表为翻译时统一使用的术语对照表。**模型只提供候选，人工确认后才能进入“已确认”。**
> 状态取值：`已确认` / `候选` / `待确认` / `保留原文`。
> 术语随各章翻译逐章扩充。
> **公式内英文的判定与译法**（哪些保留、哪些译为 `\text{...}`）：符号一律原样保留，说明性文字译出。

| 原文（公式内） | 译文 | 状态 | 备注 |

| otherwise（cases 行） | 其他情形 | 已确认 | |
| for / for all / such that / with | 对／对所有／使得／满足 | 已确认 | 存在量词后的 with 译“使得” |
| converges / diverges | 收敛／发散 | 已确认 | 动词，译为 `\text{...}` |
